# LisM — 3Dモデル

モジュールを交換できる分割キーボード **LisM** のケース・キーキャップの3Dデータを公開しています。
このリポジトリでは3Dモデルを管理し、製品紹介やビルドガイドはWebサイトで案内しています。

## ドキュメント

- [LisM 製品紹介](https://4mplelab.github.io/LisM/)
- [ビルドガイド](https://4mplelab.github.io/LisM/build_guides/)

## 3Dデータ

データ形式は **STEP** です。

| 種類 | 保存先 |
| --- | --- |
| 本体ケース | [3d-data/case](3d-data/case/) |
| モジュールケース | [3d-data/case/modules](3d-data/case/modules/) |
| トラックボールユニット | [3d-data/case/units](3d-data/case/units/) |
| 旧型ケース | [3d-data/case/old_type](3d-data/case/old_type/) |
| キーキャップ | [3d-data/keycaps](3d-data/keycaps/) |

印刷前に、[ケースの印刷条件・オブジェクト構成](3d-data/case/README.md)や[キーキャップの説明](3d-data/keycaps/README.md)をご確認ください。
本体ケースのファイル名にある `v1.x.x` は、対応するPCBのバージョンを示します。
