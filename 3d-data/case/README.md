## 推奨印刷条件

各データは以下の条件で最適化されています。  
環境によっては正常に印刷できない可能性があります。

- 本体  
   `Bambu Lab P1S`, `0.4mmノズル`, `Standard品質`  

- その他 (モジュール・トラックボールケース)  
   `Bambu Lab A1 Mini`, `0.2mmノズル`, `Standard品質`

## STEPファイルのオブジェクト構成について

一部のSTEPファイルには、複数のデザインバリエーションが重なった状態で格納されています。(例: 本体ケースの、フラットデザイン・フローティングデザイン・リブ)  
任意の組み合わせ(例: フラットのみ、フローティング+リブ など)で印刷できるよう、CAD上でオブジェクトの表示/非表示を切り替えてご利用ください。

⚠️ 一部のオブジェクトが他のオブジェクトの陰に隠れて見えない場合があります。  
印刷前に、STEPファイル内のオブジェクト構成を必ずご確認ください。

## ファイル名のバージョンについて

`v1.x.x`の表記は、ケースのバージョンではなく**PCBのバージョン**を示しています。  
バージョンがご不明な場合は、PCB基板に印字されていますのでご確認ください。
